## Antes de entregar
- Ejecuta los comandos y verifica la salida.
- Revisa git status antes del commit y del push.
- Lee los logs de Actions si algo falla.
- Verifica las rutas de artefactos.
- Añade las capturas solicitadas.
- No subas secretos, tokens ni contraseñas.
